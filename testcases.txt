Enter correct email and password and click "Login” Button – User is successfully logged in and redirected to the dashboard.
Enter an email that is not registered and click "Login" – Error message is displayed: "The email is not registered."
Enter valid task details and submit – Task is successfully created and appears in the task list.
Attempt to create a task without entering a title and description – Error message is displayed: "This field is required."
Click "Delete" on an existing task – Task is removed from the task list and a success message is displayed.
Edit a task's details and submit – Task is updated successfully and changes are reflected in the task list.
Attempt to create a task with a title exceeding 100 characters – Error message is displayed: "Title exceeds the maximum limit of 100 characters."
